# SEO 工具站 8 周日历计划

> 基于 `manual.md` 整理。目标是按每天最低 2 小时推进，空闲时扩展到 4-8 小时，把 SEO 学习、关键词挖掘、工具站建设、上线运营和复盘追踪串成一套可执行计划。

## 执行原则

- 最低投入：每天 2 小时，保证不断线。
- 标准投入：每天 4 小时，学习 1.5 小时，实操 2 小时，记录 0.5 小时。
- 加速投入：每天 8 小时，上午学习，下午实操，晚上复盘和迭代。
- 每周产出：至少 1 个可检查成果，不只看教程。
- 每天记录：完成内容、发现的问题、下一步动作。
- 每周复盘：用数据和产物判断是否推进，而不是靠感觉。

## 8 周总路线

| 周次 | 主题 | 核心任务 | 周产出 |
|---|---|---|---|

| 第 2 周 | 进阶教程速览 | 看 new.web.cafe 进阶教程和新手入门 | 网站建设流程脑图 |

| 第 5 周 | 工具落地页设计 | 学习工具落地页结构，拆优秀页面 | 首页/落地页文案大纲 |

## 工具站选题评估表

| 维度 | 评分 1-5 | 判断问题 | 记录 |
|---|---:|---|---|
| 需求明确度 |  | 用户是否明确知道自己要解决什么问题？ |  |
| 搜索意图 |  | 搜索结果是否能被一个工具页满足？ |  |
| 竞争强度 |  | 首页是否被大站、强品牌、权威内容占满？ |  |
| 实现难度 |  | 2 周内能否做出可用 MVP？ |  |
| 内容扩展 |  | 是否能继续写教程、案例、FAQ？ |  |
| 变现可能 |  | 是否可能接广告、会员、联盟或导流？ |  |

判断建议：

- 24 分以上：优先做。
- 18-23 分：可以做，但要缩小范围。
- 17 分以下：先放入候选池，不急着开工。
