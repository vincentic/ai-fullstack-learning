HTML/CSS/JavaScript、Servlet、Tomcat、MySQL 与 Spring Boot 串联起来，建立从页面到数据存储的完整开发闭环。

前端页面结构与交互 HTTP、接口、数据库建模 Spring Boot 服务与部署流程

阶段 3 · AI 与应用落地

理解大模型原理、RAG、向量数据库与 Spring AI，把后端能力升级成真正可交付的智能应用方案。

Prompt、Embedding 与 RAG 向量数据库和知识库检索 AI 项目实战与线上迭代
